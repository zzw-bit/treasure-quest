# 寻宝奇缘

一个纯前端的寻宝小游戏：点「开始寻宝」，探险家会沿着地图一站一站走下去，
一路解开线索、破译文字、找钥匙、读星象图、闯神庙，最后开箱。
整条剧情由 Promise / async-await 驱动，配 Canvas 手绘动画。

## 运行

纯静态页面，没有构建步骤，也没有任何第三方依赖。

- **直接打开**：双击 `index.html` 即可。
- **本地服务器**（推荐）：

```bash
cd treasure-quest
python -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080
```

也可以把整个目录丢到任意静态托管（GitHub Pages / Vercel / 对象存储）上，
不需要任何额外配置。

## 玩法

- 点「开始寻宝」或按 **空格键** 出发，方向键 / WASD 可以手动操控探险家走动。
- 三种难度影响守卫出现率、陷阱率与初始金币。
- 拿到的道具会点亮背包格子，部分道具可以点击使用。
- 左下角「图鉴」里能看到最高金币、最快通关等历史记录（存在 `localStorage`）。
- 右侧可以切换 `async/await` 与 `Promise 链式` 两种写法，代码面板会同步展示。

## 文件结构

```
index.html     页面结构
style.css      样式
bus.js         事件总线（逻辑层与渲染层的解耦桥梁）
audio.js       音效，Web Audio 实时合成，无音频文件
treasure.js    剧情逻辑层，只广播事件，不碰 DOM
scene.js       Canvas 渲染层，角色、镜头、粒子与特效
main.js        显示层，订阅事件并更新界面
```

加载顺序：`bus.js → audio.js → treasure.js → scene.js → main.js`

## 一些实现上的取舍

- **事件总线**：剧情代码只 `Bus.emit`，界面只 `Bus.on`，两边互不相识。
  好处是 `treasure.js` 不引用 `document`，换一套界面不用改剧情。
- **可中断的定时器**：等待统一走 `Timers.delay` 而不是裸 `setTimeout`，
  这样暂停、倍速、重开一局的清理才对每一步都生效。
- **暂停**：剧情等待、动画、计时、音效一起冻结，暂停时长不计入成绩。
- **分关推进**：在站点之间插一道"闸门" Promise，而不是把剧情切成 5 段，
  两种异步写法因此共用同一套结构。
- **音效**：用振荡器和噪声实时合成，零音频文件，不怕资源缺失。
- **动画**：角色是分段绘制的小人，沿贝塞尔曲线采样出的点行走；
  站点图标、粒子、特效全部用 Canvas 现画，不使用图片素材。
